# Virtual Works Lab Data Analytics Intern Tasks

A comprehensive data analytics project focused on healthcare, pharmaceutical sales, pharmacovigilance, and predictive analytics. This repository contains multiple internship tasks performed using Python, Pandas, Matplotlib, Seaborn, and Jupyter/Google Colab.

## Project Overview

This project analyzes real-world healthcare and pharmaceutical datasets to uncover patterns in patient records, treatment trends, drug sales, adverse drug reactions (ADRs), and predictive healthcare outcomes. The work is organized into multiple tasks, each building on the previous one.

The repository includes:

1. Data cleaning and exploratory analysis of healthcare records
2. Visualization of healthcare trends and patient statistics
3. Pharmacy sales and drug category analysis
4. Adverse drug reaction analysis across African countries
5. Predictive analytics for healthcare decision-making
